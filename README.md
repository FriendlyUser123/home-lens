# Home Lens

One camera for your home and your papers. Built at GDG Build with AI × Hacktoberfest 2026 (Virginia Tech, theme: AI for Housing).

- **Move-in:** photograph each room. Gemma 4 logs visible existing damage with timestamps, and you confirm every tag. (`room/`, owned by the room-scan side of the team.)
- **Move-out (this app, `web/`):** point the camera at the landlord's deduction letter. The page is found and flattened, Gemma reads it, and every value is highlighted on the paper. You get the Virginia 45-day deadline, a flag per charge, a short request letter, and a match of each charge to your move-in photos.
- **Problem reports:** a written repair notice that starts Virginia's 14-day clock (Va. Code § 55.1-1244.1). Planned.

Information, not legal advice.

## Model

**Gemma 4, `gemma-4-26b-a4b-it`**, through the Gemini API (Gemma 4 track). Open-weight local mode: `gemma4:e4b` via Ollama.
Gemma terms of use: https://ai.google.dev/gemma/terms

Gemma does perception only: it reads the photo into fields and copies the exact printed line (a quote) for each. Dates, math and law are plain, tested code.

## Run it

```bash
cd web && npm install && npm run dev
```

API on http://localhost:8710, app on http://localhost:5180. For the real model:

```bash
cp .env.example .env   # then set GEMINI_API_KEY (https://aistudio.google.com/apikey); never commit it
export GEMINI_API_KEY=...   # or export it in your shell
```

Other commands (in `web/`): `npm test` (rules, matcher, quote locator, geometry), `npm run typecheck`, `npm run build`, `npm run shots` (headless Chrome screenshots at 390 and 1440 px into `web/shots/`, uses a fake camera and the real model), `npm run samples` (regenerates the sample letters and photos).

The camera needs HTTPS or `localhost`. On a phone, use a tunnel or the upload button.

## How it works

1. **Capture.** `getUserMedia` (rear camera) with an upload fallback. OpenCV.js (`@techstark/opencv-js`) finds the page quad (Canny, then Otsu as a fallback), corner brackets snap onto it, and the page is perspective-flattened in the browser. If no page is found, the raw photo is used.
2. **Read.** The flattened image goes to `server/index.ts`, which asks Gemma for fields plus a verbatim quote for each. In parallel, Tesseract.js (self-hosted, runs in the browser) returns word boxes.
3. **Overlay.** Each quote is fuzzy-matched to a run of OCR words (`src/lib/locate.ts`, token alignment that tolerates OCR slips but never a wrong digit). Matched values get an animated marker highlight and a connector to their card. A quote that cannot be found is flagged "Check this" and is never highlighted.
4. **Confirm, then result.** Edit anything on tap. The deadline is 45 days after the later of lease end and move-out (§ 55.1-1226), one chip per charge, and a letter.
5. **Matcher.** `src/lib/match.ts` scores each charge against room tags by object, room and wording, and proposes "Possible match · photo #12, Aug 1". You confirm or reject each one. Only confirmed matches are cited in the letter and put on a printable evidence sheet.

```
web/
  server/        Node API (index.ts, model.ts: provider switch)
  src/lib/       rules.ts (law, dates, letter), match.ts, locate.ts, quad.ts, scan.ts (OpenCV), ocr.ts
  src/screens/   Start, Reading, Confirm, Result, Photos, LetterScreen, Evidence
  public/samples sample letters, a desk photo, room photos, room-tags.sample.json
shared/room-tags.schema.json   hand-off from the room scan
```

Load your own room scan on the "Add your move-in scan" screen (a JSON file matching `shared/room-tags.schema.json`). `photo` may be a data URL or a path the app can reach.

## Data and law sources

- Va. Code § 55.1-1226 (deposit deadline, itemization, records, wear and tear), § 55.1-1208(C) (no maintenance or repair fees), § 1-210(A) (day counting). Checked on law.lis.virginia.gov, 2026-10-24. Notes in `research/vrlta.md`.
- Sample letters and photos are fictional and generated by `web/scripts/make-samples.mjs`.
- Libraries: OpenCV.js (Apache-2.0), Tesseract.js and its English data (Apache-2.0).

## Privacy

- The photo is sent to the Gemini API to be read. **The Gemini API free tier may use submitted data to improve Google products, so demo with the sample documents only.**
- For real papers, run locally: `MODEL_PROVIDER=ollama` with `gemma4:e4b`. Then nothing leaves your machine.
- OCR, page detection and matching all run in the browser. Nothing is stored by this app; the API keeps no request bodies.

## Status

Document side works end to end with the real model. Room scan integration is through the JSON hand-off only; the room-side photos in `public/samples` are placeholders.
